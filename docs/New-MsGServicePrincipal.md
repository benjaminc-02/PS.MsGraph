# New-MsGServicePrincipal

## SYNOPSIS
Create new service principal.

## SYNTAX

```
New-MsGServicePrincipal [-AppId] <String> [-Headers <Hashtable>] [-Jwt <String>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
This function creates a new service principal from an existing app registration.

## EXAMPLES

### EXAMPLE 1
```
New-MsGServicePrincipal -AppId '98a280f3-4c22-4973-afdc-8d7c12ffefa6'
```

Creates a new service principal from the app id.
